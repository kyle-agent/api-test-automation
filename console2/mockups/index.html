console2 — UI 목업

SCP API 테스트 실행 콘솔 · 라이트 테마 정적 목업 (클릭 가능, 서버 불필요)

① 선택 방식 3안 비교 →

트리+선택바구니 · Miller 컬럼 · 캔버스 직접선택 토글. 우측 "선택 결과"는 셋 공통(대상/자동폐포/생성순서).

 ② 화면 구조: 2화면 IA →

① 구성&출발(선택+DAG+분기/옵션+출발바) / ② 실행&리포트(상태띠 + 흐름▸리소스▸api 드릴다운 + 로그 drawer). 2화면 vs 3단계 vs 4탭 비교 포함.

 ③ B2 · DAG at scale (접기·focus·미니맵) →

흐름 DAG 스케일 전략. 실제 모델 전체(275 자원/59 서비스/13 카테고리) 내장. 기본 카테고리 단위로 접고(275→13), 클릭하면 펼침, 노드 클릭 = 의존 경로만 focus, 미니맵·줌·맞춤, 그림|표 토글. 진짜로 인터랙티브.

 ④ B1 · 리포트 드릴다운 (흐름▸자원·API·로그) →

평면 4탭 → master(흐름)→detail 드릴다운. 노드 클릭 시 자원·API·로그가 "그 라이프사이클"로 스코프됨(+전체 집계). API 행 펼침 → 요청/응답 + 파라미터 스키마(declared vs sent) 커버리지 힌트. 실제 vpc·subnet·port 14-step 기반.

 ⑤ 실제 앱 정적 데모 (백엔드 없이) →

목업이 아니라 진짜 console2 앱의 정적 스냅샷 — 미리 구운 /api/model · composer.graph_view DAG · 모의 실행 리포트(흐름·자원·API·로그). fetch 모킹으로 백엔드 없이 실행됨.
