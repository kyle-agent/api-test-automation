B2 · DAG at scale — 접기 · focus · 미니맵

console2 리포트의 흐름 DAG 스케일 전략 목업 (실제 앱 아님 · 정적 데이터). 실제 모델 전체 (275 자원 / 59 서비스 / 13 카테고리)를 내장해 스케일이 진짜로 느껴지게 했습니다.
문제: 실제 흐름 DAG는 약 222 라이프사이클 / 275 자원을 longest-path로 전부 그리면 가로 1마일 = 읽기 불가. 해결: 기본은 카테고리 단위로 접고, 노드를 클릭하면 의존 경로만 남기는 focus, 그리고 미니맵 + zoom-to-fit으로 다룹니다. 표 보기는 222노드보다 생성 순서 표가 더 읽기 쉽다는 점을 보여줍니다.
접힌 그래프 — 그룹 클릭 = 펼치기 · 노드 클릭 = focus(의존 경로만) · 빈 곳 클릭 = 해제 · 드래그 = 이동
미니맵
대상(target) ★ 의존(dependent) ↓ 공유(dedup) VALIDATED docs 🜂 heavy · ⛔ quota 그룹 노드 = 접힘 (count badge)
생성 순서 (위상 정렬 · longest-path level) — 현재 선택: 전체 (275 자원) 동일 선택을 그래프 대신 선형 표로. 222노드보다 읽기 쉬움.
