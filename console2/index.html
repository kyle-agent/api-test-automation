이 화면은 임시 백엔드 상태 페이지입니다. 실제 UI(레이어드 DAG 캔버스에서 category/service/resource를 선택 → 폐포 → 합성 → DAG plan → 실행 → api 단위 라이브 리포트)는 용어/구조 확정 후 이 자리에 들어옵니다. 백엔드 API는 이미 동작합니다:
  • GET /api/model — 의존 카탈로그(resource model) + 실행 단위 lifecycle + 스텝
  • POST /api/plan — 선택 → 실제 dag_planner 스케줄(공유 루트·위상 웨이브·VPC 슬롯)
  • POST /api/run — {mode:"simulate"|"live"} 실행 (안전 게이트는 요청별 opt-in)
  • GET /api/runs/<id>/events — api 단위 라이브 이벤트 스트림
실행: python tools/console2_server.py → http://127.0.0.1:9100/
